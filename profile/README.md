# MoveInfra

We move company infrastructure from AWS, Google Cloud, Azure and DigitalOcean to **EU-owned clouds**
(UpCloud, Scaleway, Hetzner, OVHcloud) at a fixed price, with live data sync and a 30-day rollback.
→ [moveinfra.eu](https://moveinfra.eu/) · [watch a simulated migration](https://moveinfra.eu/demo/)

## Open source

| Project | What it does |
|---|---|
| [cloud-exit-cost-analyzer](https://github.com/moveinfra/cloud-exit-cost-analyzer) | Helm chart that measures real CPU and memory use in your Kubernetes cluster and shows what it costs today and on UpCloud. Read-only, nothing leaves the cluster. Apache-2.0. |
| [eu-cloud-map](https://github.com/moveinfra/eu-cloud-map) | EU-owned equivalents of AWS, Google Cloud, Azure and DigitalOcean services, as open data. CC BY 4.0. |

Contributions welcome: each repository has a `CONTRIBUTING.md`. Security issues: hello@moveinfra.eu.
